### 5. std
- **意思**: 标准的缩写

### 6. main

### 9. double
- **意思**: 声明双精度变量或函数

### 10. float
- **意思**: 声明浮点型变量或函数

### 11. long
- **意思**: 声明长整型变量或函数

### 12. short
- **意思**: 声明短整型变量或函数

### 13. signed
- **意思**: 声明有符号类型变量或函数

### 14. unsigned
- **意思**: 声明无符号类型变量或函数

### 15. enum
- **意思**: 声明枚举类型

### 16. struct
- **意思**: 声明结构体变量或函数

### 17. union
- **意思**: 声明共用体（联合）数据类型

### 18. cin
- **意思**: 输入命令

### 19. cout
- **意思**: 输出命令

### 20. endl
- **意思**: end line的缩写，换行

### 21. scanf
- **意思**: 输入命令

### 22. printf
- **意思**: 输出命令

### 23. void
- **意思**: 声明函数无返回值或无参数，声明无类型指针

### 24. for
- **意思**: 一种循环语句

### 25. do
- **意思**: 循环语句的循环体

### 26. while
- **意思**: 循环语句的循环条件

### 27. break
- **意思**: 跳出当前循环

### 28. continue
- **意思**: 结束当前循环，开始下一轮循环

### 29. if
- **意思**: 条件语句

### 30. else
- **意思**: 条件语句否定分支（与 if 连用）

### 31. goto
- **意思**: 无条件跳转语句

### 32. switch
- **意思**: 用于开关语句

### 33. case
- **意思**: 开关语句分支

### 34. default
- **意思**: 开关语句中的“其他”分支

### 35. return
- **意思**: 子程序返回语句（可以带参数，也看不带参数）

### 36. static
- **意思**: 声明静态变量

### 37. const
- **意思**: 声明只读变量 （*注意是变量*）

### 38. sizeof
- **意思**: 计算数据类型长度

### 39. typedef
- **意思**: 用以给数据类型取别名（当然还有其他作用）
