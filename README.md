# Course Repo 资源目录

本仓库保存可供课程规划系统发现的跨学科课程资源。根目录 README 是面向人和模型的 Scope 地图：用于发现候选资源，而不是应用运行时数据库。

## 规划系统使用约定

规划系统可将本目录作为候选资源索引，并在执行前将候选资源与当前已部署、可执行的 provider 求交集。目录中出现数学或英语资源，不表示任一部署一定能执行它。

选择资源后，应读取其 manifest 确认身份与入口，再读取对应 `textbook.md` 了解教材事实和可据此制定的目标。

## manifest 与教材原文的权威边界

- README 是 Scope 地图，不替代运行时数据库或 `manifest.json`。
- `manifest.json` 决定 resource ID、`name`、`subject` / `domain.key`、source 路径与 activities。
- `textbook.md` 决定教材事实与重点；目录只保留发现范围，不复制教材正文。
- README 中的候选资源仍须与当前 provider 的可执行资源求交集，才可用于实际 Todo。
- `.git/`、`.tmp/` 与顶层 `测试/` 不属于生产资源范围。

## 资源维护规则

- 新增生产资源时：新增 v2 manifest 与 source，补充本目录条目，并运行校验器。
- 删除生产资源时：同时删除其目录条目，并运行校验器。
- 移动、改名或调整生产资源的 ID、name、subject 或 source 时：同步更新 manifest、目录条目和引用路径，并运行校验器。
- 仅修改教材重点时：更新 `textbook.md`；不要把教材细节复制到本目录。
