## 词族扩展

### home 相关
- home (n.) 家；家园
- hometown (n.) 家乡
- homework (n.) 家庭作业
- housework (n.) 家务
- homeless (adj.) 无家可归的
- home-made (adj.) 自制的
- homeland (n.) 祖国；故乡

### sort 相关
- sort (v.) 分类；整理
- sort (n.) 种类
- all sorts of 各种各样的
- a sort of 一种
- sort out 整理；解决

### waste 相关
- waste (v.) 浪费
- waste (n.) 废物；垃圾
- wasteful (adj.) 浪费的
- wastepaper (n.) 废纸
- wastewater (n.) 废水
- not waste 不浪费

### save 相关
- save (v.) 节约；拯救
- save (v.) 储蓄
- safe (adj.) 安全的
- safety (n.) 安全
- save money 省钱
- save one's life 救某人的命

### use / reuse / recycle
- use (v.) 使用
- reuse (v.) 再利用
- recycle (v.) 回收利用
- useful (adj.) 有用的
- useless (adj.) 无用的
- user (n.) 使用者
- recyclable (adj.) 可回收的
- recycling (n.) 回收（行业）

### different 相关
- different (adj.) 不同的
- difference (n.) 差异；不同
- differently (adv.) 不同地
- same (adj.) 相同的（反义词）
- make a difference 有影响；有作用
- be different from 与……不同

### beautiful / pretty
- beautiful (adj.) 美丽的
- beautifully (adv.) 美丽地
- beauty (n.) 美丽
- pretty (adj.) 漂亮的
- prettier (比较级) 更漂亮的
- prettiest (最高级) 最漂亮的

### stick 相关
- stick (v.) 粘；坚持（过去式 stuck）
- stick (n.) 棍子；木棍
- stick to 坚持
- stick with 坚持；继续支持
- sticker (n.) 贴纸
