# Hello, Codex! — 六年级原创科技读本

> 和 Codex 一起做读本。原创虚构教学故事，不是教材课文或实际产品演示记录；由老师演示工具操作，学生负责提出想法、阅读提示和检查作品。产品基础说明核对日期：2026-09-29。

## 产品事实与教学边界

- Codex 是 OpenAI 的编程智能体，可以帮助编写、检查、修改和调试代码。正文把它称为 `an AI tool`，便于六年级学生理解。
- 提需求时可以说明想完成的目标、有关材料、输出形式和需要保留的内容；看过结果后，再给出具体的修改要求。实际行为取决于使用环境、可用工具和权限。
- 本册的“两页班级网页读本”“翻页失败”“修改后成功”都是为说明学习方法而创作的情节，不是对产品每次运行结果的保证。Codex 的结果仍需要人检查。
- 画面展示的是原创教学示意，不是 Codex 的精确界面截图；本册不涉及安装、注册、付费或具体菜单位置。

官方参考：[OpenAI：Code generation / Use Codex](https://developers.openai.com/api/docs/guides/code-generation#use-codex)；[OpenAI：Prompting，含 Codex 提需求与检查结果的示例](https://learn.chatgpt.com/docs/prompting)。英文、译文、问题与插画均为本地原创教学内容。

## 四页英文正文与中文辅助

### 01 · Meet Codex

1. Last week, Ms Li showed her class a tool called Codex.（上周，李老师给全班介绍了一个叫 Codex 的工具。）
2. “Codex is an AI tool from OpenAI,” she said.（“Codex 是 OpenAI 的一款人工智能工具，”她说。）
3. “It can help us write, check and change computer code.”（“它能帮助我们编写、检查和修改计算机代码。”）
4. Lin had an idea: “Let's make a small class book!”（Lin 有了一个主意：“我们来做一本小小的班级读本吧！”）

### 02 · A clear plan

5. First, they drew two pages and a big Next button.（首先，他们画出两页内容和一个大大的“下一页”按钮。）
6. Ms Li typed, “Use our words in a two-page book.”（李老师输入：“用我们的文字做一本两页的读本。”）
7. “Use large letters and a Next button for page two.”（“使用大字号，再加一个打开第二页的‘下一页’按钮。”）
8. Codex wrote the code, and Ms Li opened the book.（Codex 编写了代码，李老师打开了读本。）

### 03 · Find the problem

9. Lin clicked Next, but the first page stayed on screen.（Lin 点击了“下一页”，但屏幕上仍然是第一页。）
10. “When I click Next, page one stays on screen,” she said.（“我点击‘下一页’时，屏幕上仍然是第一页，”她说。）
11. “Please make it open page two,” Ms Li typed.（“请让它打开第二页，”李老师输入。）
12. Codex changed the code, and they tried the button again.（Codex 修改了代码，他们又试了一次按钮。）

### 04 · Check and try again

13. This time, page two opened, and everyone could read it.（这一次，第二页打开了，大家都能读到里面的内容。）
14. They checked the words and tried the book on a small screen.（他们检查了文字，还在小屏幕上试了试这本读本。）
15. “Codex can make mistakes, so we should check its work.”（“Codex 也会出错，所以我们应该检查它完成的工作。”）
16. “Next week, we'll plan another book!” said Lin.（“下周，我们要设计另一本读本！”Lin 说。）

## 六年级英语知识点连接

- **六上 Unit 1 · Try your best：一般过去时与继续尝试。** 用 `Last week`、`showed`、`had`、`drew`、`typed`、`wrote`、`clicked`、`changed`、`tried` 复述已发生的制作过程。发现问题后再尝试，与单元鼓励坚持的主题相呼应。
- **六上 Unit 5 · Keeping our city clean：will 与 should。** `Next week, we'll plan another book` 表达下一步计划；`we should check its work` 表达建议。这里迁移的是句式，不是该单元的环保内容。
- **简单请求与问题报告。** `Use…`、`Please make…` 说明希望完成的行为；`When I click…, … happens` 说明操作和实际结果。学生可以先用中文把意思说完整，再套用英语句式。

## 阅读支架

| 词语 | 提示 |
|---|---|
| Codex | OpenAI 的编程辅助工具；本册用作产品名 |
| AI tool | 人工智能工具 |
| code | 代码；让计算机执行任务的指令 |
| type | 用键盘输入；过去式 typed |
| page | 一页；这里指网页读本的一页 |
| button | 按钮；Next 是“下一页” |
| click | 点击 |
| check | 检查是否符合要求 |

## 和老师一起试一试

### 先写清楚想做什么

准备自己写的两小段英文，每段两三句。先在纸上画出每一页、字号和按钮，再请老师演示以下请求：

> Use these two short texts to make a two-page web book. Keep our words. Use large letters. Add Next and Back buttons. Check both buttons. Explain your changes in simple English.

中文辅助：用这两段短文制作两页网页读本，保留我们的文字，使用大字号，添加“下一页”和“上一页”按钮，检查两个按钮，并用简单英语解释你改了什么。发出请求时要一并给出那两段短文；`these two short texts` 不能代替真正的内容。

### 再描述看到的问题

比较 `Make a book.` 和上面的请求：后者交代了内容、页数、字号、按钮及检查方法。

用这个句式说清楚问题：`When I click ____, ____ happens. I want ____.` 例如：点击 Next 后仍停在第一页，希望打开第二页。不要只说“坏了”或“不好看”。

### 最后检查结果

1. 文字是否与自己提供的两段短文一致？
2. Next 是否打开第二页，Back 是否回到第一页？
3. 在小屏幕上，文字是否清楚、按钮是否好点？
4. 能否用自己的话说出 Codex 改了什么？不明白时继续问：`Please explain this part in simple English.`

读后核对：① Codex 能帮助做什么？编写、检查和修改代码。② 谁输入请求？李老师。③ Lin 怎样说清问题？说出点击 Next 后第一页仍留在屏幕上。④ 为什么还要检查？工具会出错，作品要符合自己的目标。
